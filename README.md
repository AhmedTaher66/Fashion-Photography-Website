# Fashion Photography Portfolio
A modern and responsive fashion photography portfolio website designed to showcase photography work, services, biography, and contact information.

# Technologies Used
* HTML5
* CSS3
* Bootstrap
* Font Awesome
* JavaScript
* Google/Custom Fonts: Open Sans & Fahkwang
  
## Responsive Design

The website is designed to work across:
* Mobile devices
* Tablets
* Desktop screens
* Large desktop displays
